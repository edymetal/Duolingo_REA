# Alterações versionadas

Copie para esta pasta somente arquivos que você alterou, mantendo o caminho
relativo à pasta `decoded`. Exemplo: `overrides/res/values-pt/strings.xml`.
O comando `Build` aplica essas substituições antes de reconstruir.

Também é possível editar diretamente `decoded`, mas essas mudanças são locais.
Guarde aqui os arquivos editados antes do commit. Não coloque APKs, chaves de
assinatura ou credenciais nesta pasta. Este README não é copiado para o APK.

Não há alterações funcionais predefinidas: a primeira reconstrução serve de
referência para suas futuras mudanças.
